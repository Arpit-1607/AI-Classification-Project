# 🌸 Iris Flower Classification using Decision Tree

A simple machine learning project that classifies iris flowers into three species using the Decision Tree algorithm from Scikit-Learn.

## 📖 About the Project

This project demonstrates the basic workflow of a classification problem in machine learning. The Iris dataset is used to train a Decision Tree model that predicts the species of a flower based on four features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The model is trained and evaluated using a train-test split approach.

## 🚀 Features

* Implementation using Python and Scikit-Learn
* Decision Tree Classifier
* Train-test data splitting
* Prediction of flower species
* Accuracy evaluation
